1三件东西各是什么 先分清角色

M5Stack 是「积木式」硬件：主机负责算和显示，底座的职责是供电+扩展，面板是输入设备。三者靠排针/排母直接插在一起，不需要焊接。

大脑 · 屏幕上盖
CoreS3 主机
ESP32-S3 双核、16MB Flash/8MB PSRAM、2.0 寸触摸屏、摄像头、双麦克风+喇叭、六轴传感器、microSD 卡槽。左侧有电源键和 USB-C，底侧有 RST 复位键。
骨架 · 电池仓
Faces Bottom3 基座
600mAh 电池 + 充电电路、两侧各 5 颗 RGB 灯条、顶部 PORT.B/PORT.C 两个扩展口、背部磁吸充电触点。正面左半装主机（M5-Bus 2×30），右半装面板（22P 面板座）。
输入 · 键盘
Faces Keyboard3 面板
35 键 QWERTY，内置 STM32，通过 I2C（地址 0x08）跟主机通信。同一个按键有三层字符（黑 / 蓝 / 红），靠 aA、Fn、sym 切换，两个蓝灯指示当前层级。
CoreS3 的按键与接口位置：PWR（单击开 / 长按 6 秒关）、USB-C、底侧 RST（单击复位，长按 3 秒进下载模式，绿灯亮）。图上还带着出厂就装好的 DinBase 底座和 500mAh 电池。

2组装 4 步 约 10 分钟

先把桌面清空，准备好：Faces Bottom3 包装里的 2.5mm 内六角扳手 和 6 颗 M3×12 螺丝。全程保持断电（不插 USB-C）。

拆掉 CoreS3 背面的 DinBase 底座

CoreS3 出厂时背面拧着一个灰色的 DinBase（导轨底座，里面是 500mAh 电池）。用包装里自带的 2.5mm 内六角扳手，拧下四角的 4 颗螺丝，把 DinBase 取下来放好 —— 以后想单机用还能装回去。

取下后你就能看到 CoreS3 背面的 2×30 排母（M5-Bus）。

把 CoreS3 扣到基座的 M5-Bus 那一半

基座正面上有印着 PIN MAP 引脚表的那一半是「主机位」，旁边是一长条 2×30 的排针（M5-Bus）。把 CoreS3 的排母对准排针，垂直轻轻按到底（屏幕朝上、朝外那一面），四角螺孔对齐后拧上 4 颗 M3×12。

不要斜着硬撬，也不要按屏幕玻璃那一面。

把 Keyboard3 面板插到中间的面板座

面板背面有一条 2×11（22P）排针，基座正中间有对应的 22P 排母座（旁边印着 M5FACESIII）。排针对齐后放下去，能自然落到底就对了，然后拧 2 颗 M3×12 固定。

如果按下去明显顶住、落不到底，说明方向反了：拔出来转 180° 再试，千万不要用力压（排针插反可能让电源脚对错）。

把基座背面的电源开关拨到 1

基座外壳背面只有一个开关，就是 电池电源开关，丝印标着 1 / 0（部分批次标 ON / OFF）：1（ON）= 通电，0（OFF）= 彻底断电。拨到 1，就可以按 CoreS3 左侧 PWR 键开机了。

更正：这份手册的旧版写过「背面有两个开关」，那是错的 —— 外壳背面确实只有这一个。另一个开关（LED IO 选择开关）在主板上、被外壳盖住，只影响两侧 RGB 灯条，与键盘面板无关，不需要为它拆机（详见第 5 节末尾）。

补充（已实测）：主板那个 SELECTION 拨钮拨到丝印 Core2 / CoreS3 那一侧时，两侧灯带会出现淡蓝色流动灯效；拨到另一侧 Core 则整条灯带全白。所以「灯带是不是拨对了」看现象就能判断。

对照图：基座（能看到引脚表、M5-Bus 2×30、FACES-BUS 22P、电池、按钮）

竖着的一长条是 M5-Bus 2×30（接主机 CoreS3）；中间横着的一排是 FACES-BUS 2×11 / 22P（接键盘面板）。板上印的 PIN MAP 表是「各主控 / 面板总线该用哪根脚」的对照，CoreS3 那一行是 PORT.A 2/1、PORT.B 8/9、PORT.C 18/17、I2C 11/12、RGB LED 5。注意：两侧那 10 颗灯珠不走这张表，它们的数据线是硬连线，只经过主板上的 SELECTION 拨钮（G15 / G25 二选一），见第 5 节末尾。

电池电源开关的特写（唯一的外壳开关）

外壳背面只有这一个开关：丝印 1 / 0，1 = ON（通电）、0 = OFF（彻底断电省电）。灯灭不代表坏，先确认它真的拨到了 1。

3首次通电检查 逐条打勾

装好后先别急着编程，按下面顺序确认硬件是通的。点一下条目就能打勾。

先搞清楚键盘的这两个蓝灯：不是随便按都会亮

查了 M5Stack 官方的 Keyboard3 面板固件源码，可以给出确切结论：面板上电后默认就是「两个蓝灯全灭」（固件里默认 led_mode = 0），只有按到「修饰键」才会亮：

  • 单击 aA → 左灯常亮；单击 Fn → 右灯常亮；单击 sym → 左右灯交替闪
  • 按住 alt → 左灯快闪
  • 敲字母 / 数字 / 空格键本身：任何灯都不会亮 —— 这是设计如此，不是坏件

另外，面板每次上电（也就是主机开机的那一下）两个蓝灯会 左右交替快闪约半秒，这是面板固件写死的开机自检。所以「面板死没死」只看两件事：① 开机瞬间有没有交替快闪；② 按 aA / sym / Fn 灯有没有反应。

  • 基座外壳背面的电源开关拨到 1（ON），不是 0
  • 用 USB-C 线连接 CoreS3 左侧的 USB-C 口和电脑（或充电器）——第一次测试建议先插着线，排除电池没电
  • 单击 CoreS3 左侧 PWR 键开机：屏幕应该亮起，出现 CoreS3 画面
  • 屏幕能触摸、能亮 → 主机部分 OK（面板的电也是从主机的 M5-Bus 来的）
  • 开机那一瞬间盯着键盘：两个蓝灯有没有「左右交替快闪约半秒」→ 有闪 = 面板已经通电并跑起来了
  • 单击 aA、sym、Fn，或按住 alt：对应蓝灯有反应 → 面板通信正常
  • 拔掉 USB-C 线，机器依然开机运行 → 基座的电池供电生效了
  • 两侧灯带：拨对主板上的 SELECTION 档位后会出现灯效（CoreS3 上是淡蓝色流动）；拨错档位则整条全白 → 详见第 5 节末尾
装好后按不到 RST 键？CoreS3 的 RST 在机身底侧，装上基座后可能正好被键盘面板挡住。需要进「下载模式」刷固件时，可以先把键盘面板的 2 颗螺丝松开、把面板掀起一点按 RST，或者干脆先不装面板、只连 CoreS3 把固件刷好再组装（固件是烧在主机里的，与装不装面板无关）。
关于「磁力计读数怪」基座和 DinBase 里都有磁铁（用于磁吸充电/固定），会影响 CoreS3 板载的 BMM150 磁力计（电子指南针）。这是正常现象，不是坏件。

4让键盘活起来：刷官方演示固件 零代码 · 浏览器操作

M5Stack 官方给这套 Faces3 组合做了一个「自动识别面板」的演示固件，用浏览器就能烧录，不需要装 Arduino。烧完插上 Keyboard3 会自动进入键盘测试小游戏。

Faces3 User Demo 里有什么：自动侦测接的是哪块面板；接 Keyboard3 时 → Basic Input Test（按键输入测试）+ Keyboard Whack-a-Mole（打地鼠）。

用 Chrome 或 Edge 打开烧录页

打开官方分享页：burner.m5stack.com/share/firmware/TNP2U4（就是 Faces3 User Demo）。必须是 Chrome / Edge（用 Web Serial 串口），Safari 不行。

让 CoreS3 进入下载模式

用 USB-C 线连上 Mac，然后长按 CoreS3 底侧的 RST 键约 3 秒，等绿色指示灯亮起再松开。松手后绿灯熄灭就代表已经进入下载模式。

连上设备

在网页上点「连接 / Connect」，弹出串口列表后选 CoreS3 对应的那一项（名字通常是 USB JTAG/serial debug unit 或 usbmodem 开头的项）。CoreS3 用的是芯片原生 USB，macOS 上一般免装驱动。

点烧录并等它跑完

按页面提示点 Burn / 烧录，进度走完（约 1 分钟）后设备会自动重启。过程中不要拔线、不要断电。

玩起来

屏幕出现菜单后，用触摸屏选到键盘相关的项，或者直接插着 Keyboard3 面板开机让它自动识别。按键盘试试输入，再玩玩打地鼠。

如果浏览器这条路走不通也可以下载 M5Stack 官方的桌面版烧录工具 M5Burner（支持 macOS），在里面搜索 Faces3 User Demo 或直接刷 CoreS3 的其它现成固件。这两种方式都完全不需要写代码。
基座接口一览：顶部两个 HY2.0-4P（PORT.B / PORT.C）可以接 M5Stack 的各种传感器单元；两侧是 RGB 灯条；背部磁吸触点配合下方的充电底座使用。

5键盘怎么用 三层字符

35 个键，但每个键位印了 3 种字符（黑 / 蓝 / 红），靠 shift 类按键切换「输入层」，两个蓝色 LED 就是当前层的指示灯。

左侧蓝灯常亮 = 基底层（黑色字符：字母、数字等）
右侧蓝灯常亮 = 符号层（蓝色字符：~ ! @ # 等）
左右灯交替闪烁 = 功能层（红色字符：方向、del、ok、alt、ESC 等）
两灯全灭 = 出厂默认状态（没按任何修饰键）。敲字母键时灯不亮是正常的，别当成故障。

切换方式：aA（大小写/基底层）、sym（符号层）、Fn（功能层）单击切换，双击可以锁定。键盘上还有 TAB、alt、ESC、方向键、退格、del、ok 等常用键，方便写小工具时做菜单操作。

键盘正面：排版是 QWERTY，最下面一排是 aA / 0 / SPACE / sym / Fn。每一行上方的黑、蓝、红三种颜色分别对应三个输入层。
键盘背面：靠下沿那条 2×11（22P）排母（带 22 个小方孔的那个黑塑料块）就是要扣到基座面板座上的部分；孔下方那一排是它的焊点。注意它是排母，基座上对应的是排针，理论上反向也能套上去 —— 所以「能扣下去」不等于插对了方向，一定要用下面的方法目视确认。
怎么确认面板插的方向对不对（不用猜）
  1. 看字符方向：装好后键盘正面每个键上的字符必须是正立的，和基座上的丝印文字（比如 M5FACESIII、PIN MAP）同一个朝向。倒过来就是插反了。
  2. 看有没有到底：面板的灰色边框应该和基座贴合无缝隙；如果四周有一两毫米的缝、摇一摇还晃，就是没插到底。
  3. 看螺丝孔对位：面板四角的螺柱要和基座上的螺丝孔对齐，两颗 M3×12 应该能轻松顺滑拧进去；拧着费劲说明位置不对。

千万不要「试一下反过来能不能插」 —— 22 个脚里既有 3V3 也有 GND，插反有可能把电源脚接到信号脚上。先目视确认，拿不准就拍张照发我。

主板上的 SELECTION 开关：档位怎么拨（已在你机器上实测）

基座主板上（不是外壳背面）有一个白色拨钮，旁边竖着印 SELECTION，两端分别印 Core 和 Core2 / CoreS3。查官方原理图可以确定它的作用：两侧共 10 颗 SK6812 灯珠串成一条链，链的数据线接到这个开关的公共脚，开关在两根引脚之间二选一 ——

  • Core 那一侧 = G15（M5Stack Core / Basic / Fire 那一代主机用的脚）
  • Core2 / CoreS3 那一侧 = G25（Core2 与 CoreS3 共用这一档）

CoreS3 就拨到 Core2 / CoreS3 那一侧。判断方法不用去数丝印，看现象最快：拨对 → 主机程序能正常驱动灯带，会看到流畅灯效（CoreS3 上实测是淡蓝色流动）；拨错 → 整条灯带一直全白。全白的原因很物理：数据脚处在空闲高电平，SK6812 把持续高电平当成一长串「1」，于是 10 颗灯珠全白最亮。

它只影响左右这两条侧灯带，跟键盘面板毫无关系；拨错档也不会损坏任何硬件，放心折腾。

6供电与充电 别把电池放空

  • 日常供电：基座的 600mAh 电池通过 M5-Bus 给 CoreS3 供电，前提是背面电池开关在 ON。
  • 充电（推荐）：把基座背面往 Faces Charging3 磁吸充电底座上一放就自动吸住（Pogo Pin 触点 + 磁铁），USB-C 线插到底座上即可充电。底座还兼作立架。
  • 充电（临时）：直接给 CoreS3 左侧 USB-C 插线，也能一边供电一边给基座电池充。
  • 省电：长时间不用时把背面电池开关拨到 OFF，避免电池慢慢耗尽。
Faces Charging3 磁吸充电底座：USB-C 在正前方，底座带磁铁，基座背面一贴即合。

8下一步三条路 按需选择

硬件跑通之后，想让它做点什么，可以从这三条路里挑一条开始。前两条都不需要写传统代码。

路线 A：只玩官方现成固件（零代码，最省事）

用 M5Burner / WebBurner 烧现成固件：Faces3 User Demo（键盘游戏）、CoreS3 出厂 Demo、小聆语音助手、ESP-Claw 等。适合先熟悉设备、验证硬件。

路线 B：UiFlow2 图形化编程（拖积木，推荐入门）

官方 UiFlow2 已经内置了 Faces Keyboard3 模块，有 Normal 模式（拿到字符）和 Direct 模式（拿到具体键名，还能控制键盘 LED）。官方还提供了一键打开的示例工程，改几个积木就能做出「键盘控制小菜单」之类的应用。

路线 C：Arduino 代码（要写代码，但最自由）

官方教程里给了完整示例：装 M5Unified + M5Faces 两个库，把键盘当普通输入设备用，屏幕上实时回显按键。适合后面想做自己的小工具（记事本、快速计时、快捷键面板等）。

1What the three parts are know the roles first

M5Stack is a building-block system: the computer does the computing and display, the base handles power and expansion, and the panel is the input device. The three plug together with pin headers/sockets — no soldering.

Brain · screen unit
CoreS3
ESP32-S3 dual core, 16MB flash / 8MB PSRAM, 2.0" touch screen, camera, dual microphones + speaker, 6-axis IMU, microSD slot. Power button and USB-C on the left, RST on the bottom edge.
Frame · battery bay
Faces Bottom3 base
600mAh battery + charging circuit, 5 RGB LEDs on each side, PORT.B/PORT.C expansion ports on top, magnetic charging contacts on the back. Left half of the front takes the computer (M5-Bus 2×30), right half takes the panel (22P socket).
Input · keyboard
Faces Keyboard3 panel
35-key QWERTY with an STM32 inside, talking to the host over I2C (address 0x08). Each key carries three layers of characters (black / blue / red), switched with aA, Fn and sym; two blue LEDs show the active layer.
CoreS3 buttons and ports: PWR (single tap = on, hold 6s = off), USB-C, RST on the bottom edge (single tap = reset, hold 3s = download mode, green LED lights). The photo also shows the factory-fitted DinBase and the 500mAh battery.

24 assembly steps about 10 minutes

Clear the desk first. You need the 2.5mm hex key and the 6 M3×12 screws from the Faces Bottom3 box. Keep everything unplugged (no USB-C) throughout.

Remove the DinBase from the back of the CoreS3

The CoreS3 ships with a grey DinBase (DIN-rail base, containing a 500mAh battery) screwed to its back. Using the 2.5mm hex key from the box, undo the 4 corner screws and put the DinBase aside — you can refit it later for standalone use.

With it removed you can see the 2×30 socket (M5-Bus) on the back of the CoreS3.

Seat the CoreS3 on the M5-Bus half of the base

On the front of the base, the half printed with the PIN MAP pinout table is the “computer side”, next to a long 2×30 pin header (M5-Bus). Line the CoreS3's socket up with the header and press straight down gently until it bottoms out (screen facing up and out), then fit the 4 M3×12 screws once the corner holes line up.

Don't lever it in at an angle, and don't press on the glass.

Plug the Keyboard3 panel into the middle socket

The panel has a 2×11 (22P) header on its back; the base has the matching 22P socket in the middle (printed M5FACESIII next to it). Align the header, lay it down — it should settle naturally — then fit 2 M3×12 screws.

If it clearly stops short and won't seat, it's the wrong way round: pull it out, turn it 180° and try again. Never force it (reversed pins can connect a power pin to a signal pin).

Set the power switch on the back of the base to 1

There is only one switch on the back of the case: the battery power switch, silkscreened 1 / 0 (some batches say ON / OFF): 1 (ON) = powered, 0 (OFF) = fully disconnected. Set it to 1 and you can press PWR on the left of the CoreS3 to boot.

Correction: an earlier version of this manual claimed “two switches on the back” — that was wrong. The other switch (the LED IO selector) is on the main board, hidden under the case; it only affects the side RGB strips and has nothing to do with the keyboard panel, so don't open the case for it (see the end of section 5).

Added (measured): with the board's SELECTION slider pushed towards the Core2 / CoreS3 silkscreen, the strips show a flowing pale-blue effect; pushed the other way (Core) the whole strip is solid white. So you can judge the position by what you see.

Reference: the base (pinout table, M5-Bus 2×30, FACES-BUS 22P, battery, buttons)

The long vertical strip is the M5-Bus 2×30 (for the CoreS3); the horizontal row in the middle is the FACES-BUS 2×11 / 22P (for the keyboard panel). The PIN MAP table tells you which pins each host/panel bus uses — for the CoreS3: PORT.A 2/1, PORT.B 8/9, PORT.C 18/17, I2C 11/12, RGB LED 5. Note: the 10 side LEDs do not follow this table — their data line is hard-wired and only passes through the SELECTION slider (G15 / G25), see the end of section 5.

Close-up of the battery power switch (the only switch on the case)

Only this one switch on the back of the case: silkscreen 1 / 0, 1 = ON (powered), 0 = OFF (fully disconnected to save battery). A dark screen doesn't mean it's broken — check this switch first.

3First power-on checks tick them off

Don't start programming yet — confirm the hardware works first, in this order. Click an item to tick it.

First, understand those two blue LEDs: they don't light for just any key

M5Stack's own Keyboard3 panel firmware gives a definitive answer: after power-on both blue LEDs are off by default (the firmware defaults to led_mode = 0), and they only light for “modifier” keys:

  • tap aA → left LED on; tap Fn → right LED on; tap sym → the two LEDs blink alternately
  • hold alt → left LED blinks fast
  • pressing letters / digits / space: no LED lights at all — by design, not a fault

Also, every time the panel powers up (i.e. when the host boots) both LEDs blink alternately for about half a second — a self-test hard-coded in the panel firmware. So “is the panel alive?” comes down to two things: ① did it blink alternately at power-on; ② do the LEDs respond to aA / sym / Fn.

  • The power switch on the back of the case is at 1 (ON), not 0
  • Connect the CoreS3's left USB-C port to the computer (or a charger) — for the first test keep the cable in, to rule out a flat battery
  • Single-tap PWR on the left of the CoreS3: the screen should light up with the CoreS3 splash
  • Touch works and the screen is bright → the computer side is fine (the panel draws its power from the host's M5-Bus)
  • At the moment of power-on watch the keyboard: do the two blue LEDs blink alternately for about half a second? → blinking means the panel is powered and running
  • Tap aA, sym, Fn, or hold alt: the matching LED reacts → panel communication is fine
  • Unplug USB-C and it keeps running → the base battery is supplying power
  • Side strips: once the board's SELECTION slider is in the right position you get an effect (a flowing pale blue on the CoreS3); wrong position = solid white → see the end of section 5
Can't reach the RST button once assembled? The CoreS3's RST is on the bottom edge and the keyboard panel may cover it. To enter download mode for flashing, loosen the panel's 2 screws and lift it slightly to reach RST, or simply flash with the panel not fitted and assemble afterwards (the firmware lives in the host, so the panel makes no difference).
About “weird magnetometer readings” Both the base and the DinBase contain magnets (for magnetic charging/mounting), which affect the CoreS3's on-board BMM150 magnetometer (compass). Normal behaviour, not a fault.

4Bring the keyboard to life: flash the official demo no code · in the browser

M5Stack publishes a demo firmware for this Faces3 combination that auto-detects the panel; you flash it from the browser without installing Arduino. Afterwards, plugging in the Keyboard3 drops you straight into a keyboard test game.

What's in the Faces3 User Demo: auto-detection of the fitted panel; with a Keyboard3 → Basic Input Test + Keyboard Whack-a-Mole.

Open the flash page in Chrome or Edge

Open the official share page: burner.m5stack.com/share/firmware/TNP2U4 (that's the Faces3 User Demo). Must be Chrome or Edge (it uses Web Serial); Safari won't work.

Put the CoreS3 into download mode

Connect it to the Mac with USB-C, then hold RST on the bottom edge of the CoreS3 for about 3 seconds until the green LED lights, then release. When the green LED goes out it's in download mode.

Connect

Click “Connect” on the page and pick the CoreS3 entry from the serial list (usually USB JTAG/serial debug unit or something starting with usbmodem). The CoreS3 uses the chip's native USB, so macOS normally needs no driver.

Flash and wait

Follow the prompts and click Burn; after the progress bar completes (about a minute) the device reboots itself. Don't unplug or cut power during the process.

Play

When the menu appears, pick the keyboard entry on the touch screen, or just boot with the Keyboard3 attached and let it auto-detect. Try typing, then play whack-a-mole.

If the browser route doesn't work you can also download M5Stack's desktop M5Burner (macOS supported), search for Faces3 User Demo inside it, or flash any other ready-made CoreS3 firmware. Neither requires writing code.
Base connectors at a glance: two HY2.0-4P ports on top (PORT.B / PORT.C) for M5Stack sensor units; RGB strips down the sides; magnetic contacts on the back for the charging dock.

5How the keyboard works three layers

35 keys, but each keycap is printed with 3 characters (black / blue / red). Shift-like keys switch the “input layer”, and the two blue LEDs indicate the current layer.

Left LED on = base layer (black characters: letters, digits…)
Right LED on = symbol layer (blue characters: ~ ! @ # …)
LEDs blinking alternately = function layer (red characters: arrows, del, ok, alt, ESC…)
Both LEDs off = the factory default (no modifier held). LEDs staying dark while you type letters is normal — not a fault.

Switching: aA (case / base layer), sym (symbols), Fn (functions) — tap to switch, double-tap to lock. The keyboard also has TAB, alt, ESC, arrows, backspace, del and ok, handy for menu-driven little tools.

Keyboard front: QWERTY layout, with aA / 0 / SPACE / sym / Fn along the bottom row. The black, blue and red colours above each row correspond to the three input layers.
Keyboard back: the 2×11 (22P) socket along the lower edge (the black plastic block with 22 small square holes) is what plugs onto the base's panel header; the row below the holes is its solder pads. Note it's a socket while the base has pins, so it can also be forced on backwards — “it fits” does not mean “it's the right way round”. Always confirm visually as below.
How to confirm the panel is the right way round (don't guess)
  1. Character orientation: once fitted, the characters on every keycap must be upright, the same way round as the silkscreen on the base (e.g. M5FACESIII, PIN MAP). Upside down = inserted backwards.
  2. Is it seated? The panel's grey frame should sit flush against the base with no gap; a 1–2mm gap all round that wobbles means it isn't fully down.
  3. Screw holes: the panel's corner standoffs must line up with the base's holes; both M3×12 screws should thread in smoothly. If they bind, the position is wrong.

Never “try it the other way to see if it fits” — of the 22 pins, some are 3V3 and some are GND, so reversing can put a power pin onto a signal pin. Confirm visually first; if you're unsure, take a photo and ask.

The SELECTION switch on the board: which way (measured on this unit)

On the base's main board (not the back of the case) there is a white slider with SELECTION printed beside it, with Core at one end and Core2 / CoreS3 at the other. The official schematic settles what it does: the 10 SK6812 LEDs on both sides are chained, and the chain's data line goes to this switch's common pin, which selects between two pins —

  • the Core side = G15 (the pin used by the M5Stack Core / Basic / Fire generation)
  • the Core2 / CoreS3 side = G25 (Core2 and CoreS3 share this position)

For a CoreS3, set it to the Core2 / CoreS3 side. Don't bother counting silkscreen — read the effect instead: right → the host program can drive the strip and you see a smooth effect (a flowing pale blue on the CoreS3); wrong → the whole strip stays solid white. The reason is physical: the idle data pin sits high, and an SK6812 reads a continuous high as a long run of “1”s, so all 10 LEDs go full white.

It only affects the two side strips and has nothing to do with the keyboard panel; the wrong position can't damage anything — experiment freely.

6Power and charging don't drain the battery flat

  • Normal power: the base's 600mAh battery feeds the CoreS3 through the M5-Bus — provided the battery switch on the back is ON.
  • Charging (recommended): just place the base onto the Faces Charging3 magnetic dock; it snaps on (pogo pins + magnets) and you plug USB-C into the dock. The dock doubles as a stand.
  • Charging (temporary): plugging USB-C straight into the CoreS3 also powers it and charges the base battery.
  • Saving power: for long storage, set the battery switch to OFF so the battery doesn't slowly drain.
Faces Charging3 magnetic dock: USB-C on the front, magnets in the base — the device snaps on.

8Three paths forward pick one

Once the hardware works, choose one of these to make it do something. The first two need no traditional code.

Path A: only official ready-made firmware (no code, easiest)

Use M5Burner / WebBurner to flash existing firmware: Faces3 User Demo (keyboard games), the CoreS3 factory demo, the XiaoLing voice assistant, ESP-Claw, etc. Good for getting familiar with the device and proving the hardware.

Path B: UiFlow2 block programming (drag and drop, recommended for starters)

UiFlow2 already ships a Faces Keyboard3 module with a Normal mode (get characters) and a Direct mode (get specific key names, and control the keyboard LEDs). Official one-click example projects are available too — change a few blocks and you have a “keyboard-controlled menu” app.

Path C: Arduino code (requires coding, but most freedom)

The official tutorial has a full example: install M5Unified + M5Faces, treat the keyboard as a plain input device and echo keys on screen in real time. The way to go if you later want your own tools (notepad, quick timers, shortcut panels…).
