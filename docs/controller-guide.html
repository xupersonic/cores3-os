CoreS3 控制器 · 配对与设置

固件已刷好。设备上电后屏幕顶部显示「BLE 等待配对」，按下面三步走完即可使用。

1蓝牙配对（只需做一次）

免密配对，不会出现输密码的弹窗。

  1. Mac 打开 系统设置 → 蓝牙（或点菜单栏蓝牙图标）。
  2. 稍等几秒，下方「附近的设备」里会出现 CoreS3 Controller。
  3. 点 连接。不需要输入配对码。
  4. 连上后 CoreS3 屏幕顶部会变成 「BLE 已连接」。
配对成功后是永久记住的，以后 CoreS3 一开机就会自动连上，不用再操作。

2设置听写快捷键（只需做一次）

让 CoreS3 的语音键能唤起 Mac 自带的听写。

  1. 打开 系统设置 → 键盘，往下找到 「听写」。
  2. 打开听写的开关，语言选 普通话（中国大陆）。
  3. 点 「快捷键」 弹出菜单 → 选 「自定…」 → 按下 Control+Option+D。
固件默认发的就是 Control + Option + D。若你想换组合，改 config.h 里的 DICT_MODS / DICT_KEY 重新烧录，两边保持一致即可。
想更快更私密：在同一页勾选「仅离线听写」（需先下载离线语言包）。

3设置中文预设（可选，但很值）

HID 键盘打不了中文，靠系统「文本替换」把缩写码展开成中文长指令。

  1. 打开 系统设置 → 键盘 → 文本替换，点 +。
  2. 「输入」填缩写码，「替换为」填你想要的那句中文指令。
输入（缩写码）替换为（改成你常用的）
;;daily帮我列出今天要做的事，按优先级排序
;;mail帮我整理今天邮件里的要点和待回复项
;;sum总结当前项目的进展、风险和下一步
;;plan帮我规划今天的工作安排，留出深度工作时间
用 ;; 开头是为了避免和正常打字冲突。缩写码只能用英文和符号。

4按键对照

CoreS3 上发给 Mac作用

「发送」/ 键盘回车Return把输入框里的内容发出去

5日常用法

  1. 点大按钮（或按空格）→ 屏幕变「正在听写…」。
  2. 对着 Mac 说话 —— 文字会落在当前光标所在的输入框里。
  3. 点「发送」→ 发出去。
听写输入的是「当前有光标的输入框」，所以先点一下 WorkBuddy 的输入框再说话。这是 VibeKey 同样的工作方式。

6出问题怎么办

现象处理
一直显示「等待配对」CoreS3 断电再上电；Mac 蓝牙关掉再开；串口发 unpair 重启广播
蓝牙列表里搜不到确认 Bottom3 底部开关拨到 1；设备靠近 Mac
按键后屏幕闪红说明没连上，先完成配对
按语音键没反应检查系统设置的听写快捷键是不是 Control+Option+D
预设打出的是英文缩写文本替换没配上，检查「输入」列是否完全一致
设备不定时重启不要打开 ENABLE_BOTTOM3_LED（灯带在 ESP32-S3 上有已知崩溃 bug）
串口命令（USB 连着时可用）：status 看连接状态 / unpair 重启蓝牙广播。

CoreS3 Controller · Pairing & Setup

The firmware is already flashed. After power-up the screen shows “BLE waiting for pairing” — follow the three steps below.

1Pair Bluetooth (once only)

Just-works pairing — no PIN dialog will appear.

  1. On the Mac open System Settings → Bluetooth (or click the Bluetooth icon in the menu bar).
  2. After a few seconds CoreS3 Controller appears under “Nearby Devices”.
  3. Click Connect. No passkey is required.
  4. Once connected, the CoreS3 status bar changes to “BLE connected”.
Pairing is remembered permanently: from now on the CoreS3 reconnects automatically at power-on.

2Set the dictation shortcut (once only)

Lets the CoreS3 voice key trigger macOS dictation.

  1. Open System Settings → Keyboard and scroll down to Dictation.
  2. Turn Dictation on and pick Mandarin (Mainland China) as the language.
  3. Click Shortcut → Customize… → press Control+Option+D.
The firmware sends exactly Control + Option + D. To use another combination, change DICT_MODS / DICT_KEY in config.h and reflash — just keep both sides in sync.
For faster, fully offline dictation, tick “Use Enhanced Dictation” on the same page (requires downloading the language pack first).

3Set up Chinese presets (optional, but worth it)

A HID keyboard can't type Chinese — macOS Text Replacement expands short codes into long Chinese prompts.

  1. Open System Settings → Keyboard → Text Replacements and click +.
  2. Put the short code in “Replace” and the Chinese prompt you want in “With”.
Replace (code)With (make these your own)
;;dailyList what I need to do today, sorted by priority
;;mailSummarise the key points and pending replies in today's email
;;sumSummarise the current project's progress, risks and next steps
;;planPlan my day, keeping a block of deep-work time
The ;; prefix avoids clashing with normal typing. Codes may only contain English letters and symbols.

5Everyday use

  1. Tap the big button (or press Space) → the screen switches to “Recording…”.
  2. Speak towards the Mac — the text lands in whichever input box currently has focus.
  3. Tap “Send” → it goes out.
Dictation types into “whatever box has the cursor”, so click the WorkBuddy input box first. This is exactly how VibeKey works too.

6Troubleshooting

SymptomFix
Stuck on “waiting for pairing”Power-cycle the CoreS3; toggle Bluetooth off/on on the Mac; send unpair over serial to restart advertising
Not visible in the Bluetooth listMake sure the switch on the bottom of Bottom3 is set to 1; move the device closer to the Mac
Screen flashes red after a keypressNot connected yet — finish pairing first
Voice key does nothingCheck that the dictation shortcut really is Control+Option+D
Presets come out as the raw codeText Replacement isn't matching — check the “Replace” column character for character
Device reboots at randomLeave ENABLE_BOTTOM3_LED off (the LED strip has a known crash bug on the ESP32-S3)
Serial commands (while USB is connected): status shows the link state, unpair restarts BLE advertising.
