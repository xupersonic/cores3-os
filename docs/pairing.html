Mac 侧日常维护 3 件事

  1. 开机自动跑：注册 launchd（com.cores3os.bridge）后，下次登录生效；这次想手动开就双击 启动桥接.command。
  2. 改 Wi-Fi：不用重新烧固件。串口发 wifi YOUR_SSID YOUR_PASSWORD，设备会存进闪存并重启；reset 可恢复默认。
  3. 登录过期：CLI 的令牌约 3 天到期，到期后双击 登录.command 走一次交互登录即可。
桥接服务只做一件事：收 HTTP 请求 → 起一个 CLI 子进程 → 把结果写回 outbox 供设备轮询。它不碰你的界面、不需要辅助功能权限。

反向：让 WorkBuddy 主动找设备 MCP

  1. 已写好 MCP Server：~/.workbuddy/m5-bridge/mcp_cores3.py（零依赖，stdio）。
  2. 已登记进 ~/.workbuddy/mcp.json，名字 m5-cores3。
  3. 还需你做一步：重启 WorkBuddy，到连接器管理页对新出现的 m5-cores3 点「信任」。
工具效果
cores3_display在 CoreS3 屏幕上显示一段文字（中文可）
cores3_led控制 Bottom3 两侧 10 颗 RGB 灯
cores3_status查设备在线状态、电量
cores3_last_result取回最近一次任务的结果
方向说明：MCP 只能由 WorkBuddy 主动发起，所以「设备 → 派活」走 HTTP 桥接、「WorkBuddy → 设备」走 MCP，两条路是分开的、各自都通了。
