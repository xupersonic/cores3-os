三步跑起来

  1. 接线：CoreS3 底边 22P 座对准 Faces Bottom3，再把 Keyboard3 压到 Bottom3 上（方向见装配手册）。
  2. 烧录：cd tools && ./fw.sh（自动探测串口、编译、上传、同步 RTC）。Arduino IDE 用户可直接打开 firmware/cores3_shell/cores3_shell.ino。
  3. 配对：Mac 蓝牙里连 CoreS3 Controller；想用音乐遥控和笔记同步，再跑 mac-bridge/build.sh 启动 Bridge。

v0.3 Wi-Fi Quick Reference

In the v0.3 days the CoreS3 joined Wi-Fi and polled an HTTP bridge service, so you configured an SSID/password, watched the IP address and installed a launchd job. Current v0.7.x is pure BLE. This page is kept for history only — not current guidance.

Up and running in three steps

  1. Wire it up: seat the CoreS3's bottom 22-pin connector onto the Faces Bottom3, then press the Keyboard3 onto the Bottom3 (orientation in the assembly guide).
  2. Flash it: cd tools && ./fw.sh (auto-detects the serial port, compiles, uploads, syncs the RTC). Arduino IDE users can just open firmware/cores3_shell/cores3_shell.ino.
  3. Pair it: connect to CoreS3 Controller in macOS Bluetooth. For the music remote and note sync, also run mac-bridge/build.sh to start the Bridge.
